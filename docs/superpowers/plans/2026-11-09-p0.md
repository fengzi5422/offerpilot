# OfferPilot P0 Implementation Plan

> **For agentic workers:** Use subagent-driven-development with disjoint file ownership, spec review followed by code quality review. Steps use checkboxes for tracking.

**Goal:** Deliver the approved Windows local P0 app with persistent tasks, EML/QQ ingestion, review, reliable reminders, backup and install tooling.

**Architecture:** FastAPI/SQLAlchemy/SQLite own all business state; Vue builds into local static assets. Blocking adapters run outside request/event-loop work. All third-party credentials remain in Windows keyring.

**Tech Stack:** Python 3.12, uv, FastAPI, SQLAlchemy 2, Alembic, Vue 3, TypeScript, Vite, Windows Toast, PyInstaller.

Run uv run pytest backend/tests/test_tasks.py and observe missing implementation failure.
2. Implement backend/app/{db,models,schemas}.py and services/tasks.py; repeat tests until green. All task mutations and reminder plans commit together.
3. Write backend/tests/test_mail.py for duplicate EML, multi-actions, ambiguous 48h, reschedule safety, ignored mail, unsafe HTML, UIDVALIDITY. Implement adapters/mail.py, services/parser.py, services/mail.py. Use synthetic samples, no user mailbox in tests.
4. Write backend/tests/test_reminders.py for claim, complete/send race, expired reminder, unknown delivery and restart recovery. Implement services/reminders.py plus injectable notification adapter.
5. Write backend/tests/test_api.py for bootstrap, unauthenticated read, foreign Origin/Host, CSRF, idempotency and version conflict. Implement app factory and routers with typed contracts in spec M11.
6. Write backend/tests/test_backup.py for roundtrip, secret absence, malicious zip, invalid schema, rollback. Implement backup and privacy services with native SQLite snapshot and isolated validation.
7. Run uv run pytest backend/tests -q and uv run ruff check backend; commit backend only after tests pass.
