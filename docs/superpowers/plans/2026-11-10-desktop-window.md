# 独立桌面窗口与启动修复

用户要求修复安装启动即 NOT_FOUND，并明确不再依赖浏览器，采用独立适配界面。本轮直接执行该授权，保留现有程序与业务数据，不自动终止用户实例。

## 已确认原因

用户提供端口 9212，与默认数据目录控制文件一致。公开 GET / 和 /index.html 返回 404，health 正常。运行进程来自桌面 offerpilot1 的旧便携目录，缺少 _internal/frontend/dist；当前用户安装目录资源完整。现有单实例逻辑遇到旧实例会命令旧实例打开浏览器，导致新安装仍跳转到旧实例。旧程序资源丢失后 StaticFiles 直接返回 JSON 404，缺少启动检查。

## 设计

- pywebview + Windows WebView2 内嵌现有 Vue 界面，独立可缩放窗口、原生文件选择/保存，界面不启动外部浏览器；会议等外部链接由系统打开。
- WebView2 为渲染运行时，不要求安装或打开浏览器；无法使用时显示中文恢复指引，不退回浏览器或老旧内核。
- 本地服务和持久化合同沿用，仍只监听回环地址，使用一次性启动码、会话和 CSRF；不向网页暴露文件系统/Python 方法。
- 主线程运行窗口消息循环，服务和托盘独立线程。关闭窗口默认隐藏至托盘；托盘退出显式停止窗口及服务。无托盘测试模式关闭即退出。再次启动只唤起已有桌面窗口；旧版占用数据目录时明确提示退出旧版，不再盲目命令旧版打开浏览器。
- 启动前验证 index.html 与引用的 JS/CSS 都在安装资源目录；缺失时中文错误提示重新完整安装，日志只记录错误码。接口的未知路径仍为真实 404，不用 SPA 回退遮掩缺失文件。
- 设置窗口最小尺寸和桌面提示，保留响应式导航；对导入、保存、日历、下载及关闭/恢复进行真实窗口验收。
- 0.2.1 打包包含窗口依赖和界面资源，新版使用原数据目录，绝不删除或迁移至空库。Windows 安装仍按当前用户，首次需可用 WebView2（系统已有），离线缺失时提供安装指引。
