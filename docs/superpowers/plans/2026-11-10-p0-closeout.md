# P0 收尾 Implementation Plan

> **For agentic workers:** Use executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 关闭已批准 M01/M03/M13/M14 的工程差距，以可复现测试和实机证据决定 P0 是否达到准入，达到前不规划 P1。

**Architecture:** 保留现有服务边界。邮件写入与解析使用独立持久化状态；单独 Parse Worker 每 2 秒处理最多 20 封。维护队列保存参数及进度，可安全重跑的任务重启后重新排队，恢复替换保持显式确认和独占。新增受保护正文暂存表，成功解析立即删除，最长 7 天；诊断只导出严格白名单字段。

**Tech Stack:** Python 3.12 / FastAPI / SQLite / Alembic / Vue / pytest / Vitest / PyInstaller / Inno Setup。

现有设计已获批准，本轮用户明确要求完成 P0 收尾；不重新请求设计批准。工作目录沿用 `.worktrees/p0`，分支 `codex/p0-closeout`。
