## 1. 页面与组件结构

Vue 3 + TypeScript + Vue Router；远端状态由统一 API client 管理，表单状态保留在页面，凭据不进 localStorage。拟建 `frontend/src/{pages,components,api,stores,types}`，pages 下按 onboarding/tasks/emails/settings/applications/calendar 拆分。

P0 左侧导航：今日待办、收件识别；右上角设置与通知入口。P1 开启求职看板/日历，不展示无法操作的占位页面。状态栏展示运行中/暂停同步、上次同步和问题计数。

| 页面 | 必须展示 | 核心动作 |
| --- | --- | --- |
| 今日待办 | 逾期、今天、未来七天、待确认、无时间；下一提醒 | 完成、开始、修改、延后提醒、手动新建 |
| 任务详情 | 时间精度、来源、证据、提醒历史、人工修改 | 改时间、取消、查看来源、重开 |
| 收件识别 | 类别、状态、规则/AI、同步故障 | 审核、忽略、重解析、EML 导入 |
| 审核面板 | 左侧来源证据，右侧动作建议与时间依据 | 逐项接受/编辑/忽略，选择参照 |
| 设置与诊断 | 邮箱、通知、隐私、导出备份、运行健康 | 测试、暂停、重新授权、恢复/清理 |
| 求职看板，P1 | 公司/岗位、阶段、最后更新 | 手动改阶段、关联/拆分 |
| 周日历，P1 | 时间区间、截止点、日期待确认、冲突 | 详情、调整个人准备任务 |

本轮确定信息架构与交互；字体、色彩和高保真视觉在功能设计确认后的 UI 工作包制作，不假定用户已批准某种视觉风格。

## 2. 五步向导

1. 欢迎：本地数据、只读邮箱、关机停止提醒；允许先体验手动任务。
2. 连接 QQ：输入地址/授权码、显示掩码、提供启用 IMAP 教程；测试成功才标已连接。失败保留地址但清除已提交秘密，不回填授权码。
3. 解析：默认规则。P0 告知 AI 属于后续能力；P1 启用时显示数据发送示例、服务商设置和单独同意。
4. 通知：发送固定测试，用户选择是否看到；看不到可继续并保留警告，应用内提醒可用。开机自启默认不勾选。
5. 首次同步：14/30 天/从现在开始，显示扫描与解析分别的数量；可暂停。结束进入今日待办并突出待确认项。

向导进度持久化非敏感字段，重启可续；授权码不作为表单草稿恢复。允许跳过邮箱，不把未连接误报为程序故障。

## 3. 关键交互细节

- 时间编辑控件分别展示日期、时刻、时区；日期已填时刻空仍可保存为待确认，不自动填时间。
- 相对期限审核展示“采用哪个收信时间计算”，选择后展示 UTC 转换前的本地结果供核对。
- “延后提醒”不移动企业截止；“修改时间”展示旧时间、新时间及影响的提醒。
- 来源 HTML 作为纯文本显示；打开链接前展示真实域名，用户点击才导航，使用 noopener/noreferrer。
- 完成/取消请求成功后才改变最终状态；等待中禁用重复按钮。失败保留用户编辑草稿，给重试入口。
- 版本冲突显示服务器新值和本地编辑差异，用户决定重新提交，禁止自动重试覆盖。
- 服务断开显示“本地服务未连接”，不假定只是互联网断开；浏览器会话不缓存完整业务数据作为第二事实来源。进程运行但互联网离线时本地编辑仍可用。

## 4. 空态、错误与访问性

无任务：提供手动新建/导入/连接邮箱；无识别结果：显示扫描数量和范围，不伪造成功；无通知权限：保留应用内记录及测试入口。耗时超过 1 秒显示进度，失败给原因+下一步，request_id 放可展开诊断区域。

中文默认，状态有文字和图标；全键盘可操作，焦点可见，弹窗焦点约束且关闭后返回触发按钮。200% 缩放不遮挡关键按钮；最小点击区建议 40×40 CSS px；颜色对比按可访问性检查执行，不单靠红绿表达。

## 5. 刷新与性能

可见页面每 5 秒刷新运行状态；任务列表操作后失效重取；后台标签页降为 30 秒，不轮询全部邮件正文。列表服务端分页，详情按需取；卸载页面取消请求。前端不自行计算提醒时间或判断业务去重。

## 6. 验收

首启→跳过邮箱→手动任务→测试通知可独立完成；真实邮箱流程覆盖失败重试和重新授权。键盘、200% 缩放、窄窗口验证无阻塞。5 名非开发用户可不使用终端完成首启，是实际用户验收门槛，开发自动化通过不能替代这项验证。
