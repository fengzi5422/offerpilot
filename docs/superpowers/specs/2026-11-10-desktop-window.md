# 独立桌面窗口增量设计

用户已明确要求修复安装后 NOT_FOUND，并使用不依赖浏览器的独立适配界面；此授权覆盖本轮实现。实施计划见 [桌面计划](../plans/2026-11-10-desktop-window.md)，证据见 [验收记录](../../desktop-acceptance.md)。

## 启动与窗口

用 pywebview/WebView2 承载现有 Vue 事件空间，默认 1200×820、最小 720×540；保留自然滚动，窄窗口收起侧栏文字，短窗口隐藏装饰。日期、地点、导入、日历沿用事件模型，地区设置保持折叠。

主线程运行原生窗口消息循环，托盘和 Uvicorn 分别使用后台线程。默认关闭窗口隐藏，托盘退出经确认停止服务；--no-tray 模式关闭退出。--headless/旧 --no-browser 参数只用于后台验收；登录自启创建隐藏窗口和托盘。

启动前校验 index 与所有入口引用资源；失败不启动服务，不展示 JSON 404。单实例先 get_status，桌面实例才接受 open_ui；旧实例显示退出旧托盘的指引。安装不强制关闭程序。便携分发必须保持完整目录。

## 会话、文件与边界

沿用回环地址、一次性片段引导码、会话与 CSRF。页面不暴露自定义 Python API，禁止 file URL；WebView2 原生下载、上传对话框开启，会议链接 target=_blank 交系统处理。WebView2/.NET 缺失明确提示，不回落旧内核或浏览器。

主动重开时以原生 cookie 向会话管理器校验；可见且有效时仅唤起，避免丢失编辑。隐藏或会话失效时加载新引导 URL，随机 launch 查询参数确保重新挂载，令 Vue 重新认证；真实引导码只放片段，不写日志。

新代码在 scripts/desktop_runtime.py，launcher 负责装配。打包收集 webview、pythonnet、clr_loader 及原有业务依赖，应用版本统一为 0.2.1，数据结构继续 0004。既有真实实例不自动升级或退出。
