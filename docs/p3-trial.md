# 1.0.0-rc.1 真实试用

项目中`output/p3-trial-rc1/OfferPilot-候选版验收.lnk`打开独立窗口，数据写入`.runtime/p3-user-trial-rc1`，与用户原安装、默认数据及旧测试数据分开。此入口不会迁移原邮件。关闭窗口保留托盘运行；托盘退出才停止程序。不要将这个数据目录作为缓存清理。

## 优先完成的实测

1. 在设置中自行连接QQ、163或126测试账号，确认同步成功、重复同步不重复建任务。授权码只在程序内填写，无需发给开发者。
2. 自行填写AI地址、模型及密钥，阅读发送说明后启用，先用虚构内容测试，再对一封获准邮件请求AI建议；核对日期/证据，确认关闭后规则仍可用。
3. 如有接受通用JSON的公网HTTPS接收服务，在webhook设置中配置并测试，记录服务受理与手机实际可见两个结果。普通Bark/企业机器人等专用格式地址不保证直接兼容。
4. 在使用引导中发送系统测试通知，记录是否实际看见横幅；分别测试休眠恢复与程序退出期间不发送的行为。不要把接口成功当成看见通知。
5. 导入一封获准`.eml`，导出ICS与备份，实际操作系统文件对话框；在目标日历导入ICS，检查日期、时间与地点。ICS为快照，重复导入行为取决于目标日历。

每项记录：版本、系统、日期、步骤、预期、实际、通过/失败、去除个人信息的证据。密钥、完整邮件及真实数据库不作为公共验收附件。
