# OfferPilot 隐私与数据说明

本说明对应当前本机功能，说明程序实际保存和发送的内容。AI 与外部 webhook 默认关闭；本地规则、手动任务、申请看板和准备清单可以独立使用。它们不需要把数据上传到 OfferPilot 的云端账户，也不提供多设备同步或关机后的托管提醒。

## 本机保存什么

默认数据目录为 `%LOCALAPPDATA%\OfferPilot`。通过 `--data-dir` 或 `OFFERPILOT_DATA_DIR` 指定的目录是另一套独立数据，和默认目录、开发检查目录不自动混用。

当前目录可能包含：

- `data.sqlite` 及运行时数据库辅助文件：任务、时间、备注、申请阶段与历史、准备清单、邮件主题与发件人、规范化正文片段、来源证据、链接与附件元信息、账户进度、提醒及投递结果、设置和凭据引用。
- `logs`：经过字段白名单筛选的本机运行日志，不以正文、邮箱地址、密钥或完整链接作为日志字段。
- `backups`：日常 ZIP、升级前和恢复前的本机恢复点。
- 导出与临时目录：等待下载的文件、导入或恢复校验中的副本及运行所需状态。

程序不是完整邮件归档工具。只读获取必要文本，不会把所有原始 MIME 和附件作为长期邮箱副本保存；解析后的正文片段和证据仍可能含个人信息。成功解析后会清理临时解析全文缓存，失败缓存最长保留七天；保留的摘录、任务和人工填写内容不会因此全部消失。你自己保存的原始 `.eml` 文件也不会被程序代删。

**数据目录和导出文件没有由应用实施的整体加密。** 它们依赖 Windows 用户账户权限、设备安全和你选择的存储位置保护。能访问该 Windows 账户或这些文件的人，可能读取个人事项。请把数据和备份存放在受自己控制的私密目录，按需要使用系统磁盘加密；不要把整个目录直接共享给他人。

## 凭据与配置

邮箱客户端授权码、AI API Key、完整 webhook 地址及可选令牌使用 Windows 凭据管理器保存，数据库只保留必要引用。程序不使用普通明文配置文件作为备用密钥仓库。保存后的密钥不回显；界面不会通过 GET 返回完整 webhook 地址或令牌。

AI 的服务基础地址与模型名称属于可查看的配置，请不要把 Key 写在基础地址或模型字段里。Webhook 的专属路径和查询参数可能本身就是凭据，因此与令牌一起作为秘密保存。日志、诊断包和可下载备份不应包含这些秘密或可用凭据引用。

移除邮箱或删除外部服务配置会停止相应连接，并处理 Windows 中保存的凭据。若凭据管理器暂时不可用，操作可能失败或需要再次清理，以界面结果为准；不要把一次点击等同于操作一定成功。

## 邮箱连接会发送什么

仅在你添加邮箱并授权后，程序使用 QQ/Foxmail、163 或 126 的固定 TLS IMAP 服务器进行登录和同步。厂商会收到该账户地址、用于认证的客户端授权码和必要协议请求。网易还会收到客户端名称、版本等静态身份信息，不在该身份字段中放入授权码或邮箱地址。

程序只读打开收件箱，以不主动标记已读的方式获取必要内容；不发送、删除或归档邮件。各账户的凭据、进度、暂停和移除状态独立。移除账户保留已经形成的任务；原邮箱中的邮件仍由邮箱厂商保存和管理。

## AI 的外部传输与限制

AI 默认关闭。启用需要你填写兼容 API 基础地址、模型和 Key，并主动勾选对发送范围与费用的同意。更换地址或模型后要重新确认，每次保存启用配置也需主动确认。

普通识别中，规则已经充分处理的邮件不会因为开启 AI 而自动再发给模型。用户主动要求 AI 辅助识别或运行固定示例测试时，则会发起相应请求。固定测试使用虚构样例，不代表对真实邮件和服务稳定性的验收。

实际辅助请求包含必要主题、正文片段和提取事项所需的指令：主题输入最多 500 个字符，正文输入最多 12000 个字符。发送前会尽量替换邮箱、手机号和个人称呼等信息，链接缩减为域名。**脱敏不等于完全匿名**；表达习惯、公司岗位、事件日期及未识别的个人内容仍可能关联到你。自动脱敏没有覆盖所有个人信息的保证。

API Key 仅用于向你填写的服务认证，不作为邮件内容发送。接收服务还可能观察到请求时间和来源网络信息，如何保存、用于训练或转交数据，取决于该服务及你与其约定的政策。服务费用由你和服务商结算。选择本机模型时，也应确认实际运行的服务和地址由谁控制。

AI 结果仅为待审核建议，不直接代你发送邮件、提交申请或执行邮件中的指令。关闭 AI 后停止后续外部识别；更改、停用或清理后的迟到结果会受状态检查限制。已经发出的请求及接收方副本无法通过本机停用或删除来撤回。需要删除服务端数据时，请直接联系该服务商。

## Webhook 的外部传输与限制

Webhook 是可选的通用接收服务，默认关闭。只有你填写接收地址、确认发送范围并启用后，才用于外部提醒。它不自动为你建立手机账户，也不保证现有手机推送商支持当前格式；不兼容时需要你自己选择或部署可信 relay，中转服务也会成为数据接收方。

请求为公网 HTTPS JSON POST，仅包含：

| 字段 | 内容 |
| --- | --- |
| `app` | `OfferPilot` |
| `message` | `你有一项求职待办，请打开OfferPilot查看` |
| `idempotency_key` | 同一提醒重试保持稳定的防重复标识 |

填写令牌时，以 `Authorization: Bearer` 发送认证。不会把真实任务标题、邮件正文、邮箱地址或任务链接放进提醒正文。稳定标识和发送时间仍可让接收器关联同一提醒的多次请求；泛化消息不能隐藏所有使用情况。

应用校验 TLS 证书，拒绝本机、私网、链路本地及元数据地址，不跟随重定向。服务返回 2xx 仅表示受理，**不是手机送达、显示或已读回执**。认证或格式被拒绝的请求不自动重试；429 或 5xx 对定时提醒最多尝试发送三次（含首次），固定测试不自动重发。发送后超时、网络断开或无法确认响应会记为结果未知，不自动重发，避免重复提醒。

新接收地址不会自动沿用旧 Bearer 令牌。停用、删除或更换接收器会影响尚未发送的计划，但无法撤回已经写出的请求。应用退出、休眠或关机期间无法发送。Windows 通知与 webhook 的投递结果相互独立，任一通道成功不证明另一通道成功。

## 导出、备份与恢复

CSV、JSON、ICS 和备份都是本机生成的文件，由你决定保存或分享。它们不是匿名报告：任务标题、备注、申请公司岗位、准备内容和日期可能识别个人。

设置中下载的默认备份，以及日常自动 ZIP，会排除邮箱授权码、AI Key、完整 webhook 地址、令牌及可用凭据引用，并排除临时正文缓存。默认不包含来源正文片段或证据，但**仍保留业务事项、必要邮件元信息及人工输入**。你手动把原文复制进备注、标题或准备文字后，这些内容仍可能进入备份；不能由“备份不含原文”推断整份文件没有个人信息。

升级前 `pre-upgrade-*.sqlite`、恢复前 `pre-restore-*.sqlite` 等内部恢复点用于本机回滚，可能包含较完整的业务来源和凭据引用；它们与经过清理的可下载 ZIP 不同，不适合当作脱敏材料分享。结构升级到 `0005_preparations` 前会先留下本机快照。回退旧程序必须同时使用与旧结构匹配的数据；只换旧 EXE 直接打开新结构数据库不能保证兼容。

恢复会替换当前数据，不是合并。恢复后的邮箱需要重新授权，AI 与 webhook 为停用且不带外部凭据，须重新设置并主动同意后才会再次联网；不自动沿用备份中的外部服务授权。重新启用开机自动运行也需自己确认。

ICS 是一次日历快照，不是双向同步。默认只导出标题与时间；只有你主动选择时，才增加地点、会议链接、备注和受限来源信息。标题本身仍可能含个人信息。目标日历软件会成为这些信息的接收方，各家对重复导入、更新、取消和待办的处理不同，不能保证旧事件自动替换或撤回。

## 删除与仍可能存在的副本

「清除邮件缓存」清理当前邮件文本缓存；「删除来源证据」进一步清理当前库中的来源片段与证据。两者都不会自动清空任务标题、人工备注、申请资料和准备内容。若这些字段含个人信息，请另行编辑、删除或选择清理全部本机数据。

清理不会删除原邮箱里的邮件，也不会代删已经下载到其他目录的 `.eml`、CSV、JSON、ICS、备份或诊断文件。旧备份、升级前和恢复前快照可能保留删除前的信息；部分清理不会同步改写这些副本。应自行检查并单独删除不再需要的文件，以及系统备份、回收站或同步盘中由你保留的副本。

“删除全部本机数据”按界面范围清理当前数据及程序管理的相关副本，并停止当前连接；已经复制到外部位置的文件和接收服务上的内容仍需要单独处理。任何本机删除都不等同于撤回曾交给第三方的数据，也不承诺对存储介质进行取证级擦除。

## 日志与诊断

程序保存有限大小并轮换的本机运行日志。诊断包包含应用版本、模块健康、数量统计和最多 2000 条经过白名单筛选的运行日志，不包含业务数据库、邮件正文、邮箱地址、密钥或用户目录路径。

诊断仅在你点击导出时生成并下载，**不会自动上传**。收到文件后，请先检查内容，再决定是否分享给支持人员；分享本身由你控制。外部邮箱、AI 或 webhook 服务自身的日志与保留策略不由本机诊断清理功能控制。

## 证据边界与操作入口

自动化测试和虚构服务只证明对应流程的验证结果，不等于真实邮箱、实际 AI 服务、手机已读或长期稳定性证明。连续七天运行、五位独立用户试用、干净 Windows 系统安装等，需要另有真实验收记录；未完成项保持待验。

具体的配置、备份、恢复和清理步骤见[本机使用指南](user-guide.md)。
