# P3 本机版交付验收

2026-11-10。0.2.2 原包与用户程序、邮箱、数据保持原样。本轮在 `.worktrees/p0` 的 `codex/p3-local-release` 开发，所有新验收使用虚构独立目录。没有读取真实邮件或复用真实凭据，没有上传、推送或发布。

## 已修正的计划与实现问题

除最初计划审核的版本不一致、联网隐私、双通道结果混用、关联版本、旧备份兼容等问题外，独立审查及综合测试又实际复现并修复：

- AI 分段变化重复开放建议、失效密钥继续处理其他邮件、旧同意仍可出站。
- 地址解析和 TLS 阶段超时边界；撤销授权、清正文、恢复、退出后仍可能发送旧正文；合法 HTTP 关闭响应被误报失败。
- 数据提交后的日志异常错误删除新凭据，凭据清理失败无法持久重试。
- 取消/延后操作与提醒投递的锁反转；通知配置变更后丢弃已发送回执。
- 默认无证据备份、来源清理仍残留 `temporal.raw_text` 原文。
- 准备清单与任务页修改不同步，可能重开已完成任务或覆盖手写备注；退出返回后 AI 最终事务仍可能提交。

每项均使用隔离回归或独立并发模拟验证。新迁移为 `0005_preparations`，0001–0004 历史文件不修改，旧备份先严格校验并在副本迁移。

## 自动化与独立窗口证据

- `scripts/check.ps1`：后端、桌面、发布一致性测试；Ruff；前端测试与生产构建。最终结果以交付记录中的最终版本日志为准。
- `scripts/smoke_p3.py --data-dir <全新目录>`：鉴权 API、实际本机 HTTP 虚构模型服务、AI 审核、申请关联历史、准备事项、双通道结果、第三方 ICS 解析、备份恢复及关闭重开。拒绝覆盖已有目录。
- 综合流程初验：10 项检查全部通过，本机模型 HTTP 2 次、注入 webhook 3 次、注入 Windows 3 次、ICS 5 项、重开保留 5 项任务。这里是仿真结果，不代表外部服务真实通过。
- `scripts/smoke_desktop.py`：实际 WebView2 独立窗口，设置默认关闭、申请创建、邮件界面导入、2026-11-16 08:30 预填、准备模板/勾选、改期、日历、恢复失效会话、窄窗口、关窗到托盘、二次启动恢复。源码版已通过，截图 `.runtime/p3-native-source-031/`；打包版另行记录。
- `scripts/smoke_restart.py` 与 `smoke_windows.py`：最终包独立进程持久化与 Windows 运行冒烟，使用新目录，不操作用户实例。
