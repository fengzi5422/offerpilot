## A · AI（0.3.0）

主要文件：新增 `backend/app/ai.py`、`backend/tests/test_ai.py`、`frontend/src/components/AISettings.vue`；修改 `mail.py`、`jobs.py`、`accounts.py` 的凭据边界或提取共享 vault、`tasks.py` 设置、`api.py`、`SettingsPage.vue`、`Onboarding.vue`、`InboxPage.vue`、备份脱敏和诊断字段白名单。

- [ ] 配置 OpenAI 兼容接口的地址、模型、启用开关和 Key；Key 进入 Windows 凭据库，GET 设置/日志/诊断/备份均无明文。启用前明确传输内容；不读取或发送邮箱授权码。
- [ ] `AIParser.parse(text, context) -> list[Candidate]`：固定 JSON 合同，字段白名单、有限数组/字节/时长，候选证据必须对应输入文本。邮件内容仅作数据，提示注入不能执行工具或修改设置。
- [ ] 外部请求在数据库事务之外，回写检查邮件/数据库代际和版本；暂停、退出、清理或恢复后的迟到结果不得写回。规则仍能独立生成/审核和安排提醒。
- [ ] AI 只能补充建议，明确时间经确定性校验；模糊内容送审。人工修改与已接受/忽略决定优先，改期/取消必须关联原任务，失败不重复建事件。
- [ ] 测试 `test_disabled_makes_no_requests`、`test_timeout_auth_quota_invalid_json_falls_back`、`test_prompt_injection_stays_data`、`test_unsupported_fields_and_invented_quotes_rejected`、`test_manual_fields_and_late_results_protected`。使用本地模拟服务先端到端，真实连接在用户自行配置后记录结果；不得虚报真实服务可用。
